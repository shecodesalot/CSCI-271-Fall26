## What I learned
- A repository is the main storage container for a project. It keeps all your files and smaller parts organized in one location.
- A README file helps helps explain what the code in the repository does and how to use it.
- A commit records the reason in plaintext for why you made a change to any file within the repository; whether it's a .md file, .cpp file, or any other file.
